# Лаборатория Promobot M Edu — Школа №1409

Веб-приложение для управляемого доступа учеников к учебным роботам Promobot M Edu.
Ученик заходит без регистрации, вводит имя и ждёт; учитель в админке решает, кого и к
какому роботу подключить. Панель робота открывается ученику через встроенный
реверс-прокси, поэтому IP-адреса роботов не видны и лаборатория доступна за пределами
локальной сети.

## Возможности

**Ученик**
- вход по имени без пароля (`/`), страница ожидания с местом в очереди (`/wait`);
- после назначения — полноэкранный iframe с панелью робота, кнопки «Во весь экран» и «Завершить»;
- доступ живёт ровно столько, сколько его дал учитель: отзыв назначения закрывает панель.

**Учитель** (`/admin`, вход по `TEACHER_PASSWORD`)
- очередь заявок и карточки роботов: статус панели, связь по rosbridge, состояние манипулятора, версия ПО;
- назначение и отзыв учеников, отключение ученика, удаление заявки;
- живые превью панелей прямо в карточках, открытие любого робота себе одним кликом;
- аварийная остановка робота (`stop_moving`);
- одновременный запуск Python или Blockly JSON на выбранных роботах (`/admin/code`) с прогрессом, выводом и ошибками по каждому роботу;
- редактор реестра роботов (`/admin/robots`).

**Прокси**
- HTTP панели, WebSocket rosbridge и REST панели проксируются через один адрес `/p/<токен>/`;
- токен одноразовый и привязан к владельцу: чужая cookie получает 403;
- в HTML панели внедряется `panel-bridge.js`, который перенаправляет WebSocket, `fetch`,
  `XMLHttpRequest` и относительные ресурсы SPA на прокси.

## Как это работает с роботом

Панель робота — SPA на nginx (порт 80), которая общается с ROS 2 через rosbridge
(порт 9090). Приложение использует те же каналы:

| Действие | Канал |
| --- | --- |
| Состояние манипулятора | сервис `/pm_api/get_cobot_state` |
| Версия ПО | сервис `/pm_api/get_version_software` |
| Аварийный стоп | сервис `/pm_api/stop_moving` |
| Запуск Python | экшен `/pm_api/execute_code` |
| Запуск Blockly-программы | экшен `/pm_api/play_program` |

Python-код исполняется на роботе в контейнере, где объект `manipulator` создаётся
преамбулой SDK. Приложение добавляет эту преамбулу само (галочка «обёртка SDK» на
странице запуска), поэтому ученический код может сразу вызывать `manipulator.*`.

## Запуск локально

```bash
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
cp .env.example .env        # впишите TEACHER_PASSWORD и SECRET_KEY
./.venv/bin/python -m uvicorn app.main:app --reload --port 8000
```

Ученик — <http://127.0.0.1:8000/>, учитель — <http://127.0.0.1:8000/admin>.
В контейнере приложение слушает **80**.

## Развёртывание в Coolify

1. **New Resource → Application** и укажите этот git-репозиторий.
   Удобнее **Dockerfile** (Coolify сам проксирует порт контейнера). Если берёте
   **Docker Compose**, не публикуйте порт на хост — в `docker-compose.yml` стоит
   только `expose: ["80"]`, иначе получите `Bind for 0.0.0.0:80 failed`.
2. **Ports Exposes**: `80`. Health check: `GET /health`.
3. **Environment variables** — минимум:

   | Переменная | Значение |
   | --- | --- |
   | `TEACHER_PASSWORD` | пароль входа в админку |
   | `SECRET_KEY` | `python -c "import secrets; print(secrets.token_urlsafe(32))"` |
   | `DATA_DIR` | `/data` |

   Остальные переменные — в [`.env.example`](.env.example).
4. **Persistent storage**: том на `/data` — там хранятся реестр роботов и журнал запусков кода.
5. Включите домен с HTTPS. WebSocket проксируется Traefik автоматически, отдельная
   настройка не нужна.

### Главное условие: сеть до роботов

Контейнер обращается к роботам напрямую по их адресам `192.168.102.x` / `192.168.103.x`.
Поэтому сервер Coolify должен видеть эту сеть — стоять в школьной локальной сети либо
иметь до неё VPN (WireGuard, ZeroTier и подобное). Если сервер снаружи, а роботы за NAT,
понадобится туннель до школьной сети; проброс портов каждого робота в интернет не нужен
и небезопасен — прокси для этого и сделан.

После деплоя проверьте связь из контейнера (имя подставит Coolify):

```bash
docker exec -it <container> python -c "import socket; print(socket.create_connection(('192.168.103.192', 9090), 5))"
```

### Docker Compose локально

```bash
cp .env.example .env        # заполните TEACHER_PASSWORD и SECRET_KEY
docker compose up -d --build
# без Coolify добавьте в docker-compose.yml: ports: ["80:80"]
```

## Реестр роботов

По умолчанию заданы четыре робота:

| id | Название | Адрес |
| --- | --- | --- |
| `central-front` | Центральный передний | 192.168.103.192 |
| `central-back` | Центральный задний | 192.168.103.234 |
| `left-back` | Левый задний | 192.168.102.18 |
| `left-front` | Левый передний | 192.168.102.38 |

Правится на `/admin/robots` и сохраняется в `DATA_DIR/robots.json` (этот файл имеет
приоритет над `ROBOTS_JSON` и значениями по умолчанию). Поля робота: `id`, `name`,
`host`, `panel_port` (80), `ros_port` (9090), `rest_port` (8081), `enabled`.

## Структура

```
app/
  main.py           сборка FastAPI, lifespan, /health
  config.py         настройки и реестр роботов
  state.py          сессии учеников, очередь, назначения, токены панелей
  monitor.py        фоновый опрос статусов роботов
  rosbridge.py      клиент rosbridge: сервисы и экшены ROS 2
  programs.py       Blockly JSON → формат робота, обёртка Python SDK
  runner.py         параллельный запуск кода, статусы, журнал
  proxy.py          реверс-прокси панелей (HTTP + WebSocket + REST)
  security.py       cookie учителя и ученика
  routes_public.py  страницы ученика
  routes_admin.py   админка и её API
  static/, templates/
```

## Безопасность

- Пароль учителя и `SECRET_KEY` задаются только через окружение; дефолтный пароль
  выводит предупреждение в лог при старте.
- Cookie учителя и ученика подписаны (`itsdangerous`), панельный токен проверяется
  на каждом запросе и на каждом WebSocket-соединении.
- Проксировать WebSocket разрешено только на порты из белого списка (`ALLOWED_WS_PORTS`).
- Приложение снимает у панели `X-Frame-Options` и CSP, чтобы она открывалась в iframe;
  делайте это только для доверенных адресов роботов из реестра.
- Ученики не видят ни IP роботов, ни портов — только `/p/<токен>/`.

Одновременный запуск на роботах

Код уходит на выбранных роботов параллельно. Python выполняется действием execute_code. Файл Blockly с панели робота тоже уходит туда: JSON точек и блоков сначала переводится в Python SDK, как это делает сама панель.

JSON Blockly с панели или .py
С обёрткой доступен объект manipulator, как на вкладке Python в панели: move_to_angles(...) (углы в радианах, параметр velocity_factor), move_to_coordinates(x, y, z), get_joint_state(). Вывод print вернётся сюда. Снимите галочку, если пишете полностью самостоятельный скрипт.
Вставьте или загрузите JSON, который панель сохраняет кнопкой «скачать» (jointPoints, cpiPoints, program.blocks). Он будет превращён в Python и выполнен так же, как на роботе. Также принимаются программа с ключом Root и простой список {"blocks":[{"type":"move_joints","positions":[0,20,20],"velocity":0.3}]}.

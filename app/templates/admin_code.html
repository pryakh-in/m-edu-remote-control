Одновременный запуск на роботах

Код уходит на выбранных роботов параллельно: Python выполняется действием execute_code, программа из блоков — сохраняется и запускается как Blockly-программа панели.

С обёрткой доступен объект manipulator, как на вкладке Python в панели: move_to_angles(...) (углы в радианах, параметр velocity_factor), move_to_coordinates(x, y, z), get_joint_state(). Вывод print вернётся сюда. Снимите галочку, если пишете полностью самостоятельный скрипт.
Вставьте программу панели с ключом Root или простой список блоков: {"blocks":[{"type":"move_joints","positions":[0,20,20],"velocity":0.3},{"type":"delay","time":1}]}. Поддерживаются move_joints, move_cartesian, point, delay, audio, gpio.
